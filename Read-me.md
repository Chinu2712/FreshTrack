FreshTrack

Main dashboard for First year undergrads with Tools to help them 
We made it using HTML5 CSS3(no tailwind) and JavaScript (with few libraries)

things we added to FreshTrack->
1. Startup Animation
2.  attendance calculator (along with warning tags (below 75%))
3.  Cgpa Calculator
4.  Budget Calculator
5.  Charts/Graphs (for better understanding)
6.  Fonts / Logos
7.  Contact Option

@ Startup Animation
I.  using JAVAScripts in built functions to add a welcome / startup screen before the main animation with a button to end the animation early 

@ Attendance Tracker 
I. first variable for total classes (total)
II. second variable for total classes attended (attended)
III. third variable for the mathematical logic (percentage) / percentage = (attended / total) * 100
IV. Last Variable to display the result along with display variable (in sync with pop html)

@ CPGA Calculator
I. first variable for first sgpa (sgpa1)
II. second variable for second sgpa (sgpa2)
III. third variable for the mathematical logic (cgpa) cgpa  = (sgpa1 + sgpa2) / 2
IV. last variable to display the result along with fixated to 2 decimal places 

@ Budget Tracker
I. first variable for total budget
II. second variable for expense
III. third variable for the mathematical logic (balance) balance = budget - expense
IV. Last variable to display the balance in rupees

@ Chart (pie chart)
I. integrating pie chart for the budget tracker using (chart.js)

@ Font/Logos
I. using font awesome library to add logos in the sidebar  

@ Contact Linking
I. Using access key to give access to a email id to automatically direct email to a designated Address.
II. Along with the recepient receiving the email at their address
